4. Ensure-indexed contract
ensure_memory_indexed zwraca EnsureMemoryIndexedResult(memory_id, state).
Stany: INDEXED albo ALREADY_INDEXED.
Compatible existing vector: ALREADY_INDEXED, zero embedding, zero upsert.
Missing vector: przygotowanie embeddingu i krótki caller-owned vector commit.
Incompatible vector: MemoryIndexingIncompatibleError, zero overwrite.
Nieistniejąca canonical Memory: MemoryIndexingMissingError, zero resurrection.

12. Indexing failure semantics
Canonical save failure nadal jest memory.save_failed / SAVE_FAILED.
Po canonical commit indexing failure jest odrębnym memory.index_failed:
"The memory was saved, but semantic indexing could not be completed. Retry is available."
recoverable=true.
Canonical Memory pozostaje durable, nigdy nie jest rollbackowana/deletowana
z powodu awarii derived vectora. Public error nie zawiera contentu, vectora,
SQL parameters, raw provider payload ani credentials.
Embedding deadline: 120 sekund; timeout mapowany do controlled indexing error.
Cancellation propaguje, nie jest zamieniana w zwykły błąd.
