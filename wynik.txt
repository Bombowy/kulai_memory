3. Chosen voice mode separation
Jawny DesktopVoiceMode: NOTE lub QUESTION. Brak automatycznego rozpoznawania intencji.
NOTE: recorder -> Whisper -> istniejący save Memory -> automatic indexing -> Recent Memory.
QUESTION: recorder -> Whisper -> istniejący ask_memory -> answer/citations.
Question nie alokuje ingestion_id ani VoiceSession/session_id, nie uruchamia ingestion ani indexing write, nie odświeża Recent Memory.
Operation lock i mode/task guards wykluczają równoległe note, text ASK, question, STT/save/indexing i pending retry. UI blokuje konfliktujące przyciski.

8. State machine
Idle -> Opening microphone... -> Listening... -> Transcribing question... -> Searching memory... -> Generating answer... -> Answered.
Unsupported: Not enough information + canonical insufficient answer + zero sources.
No speech: No speech detected -> idle.
Failure: safe public message, answer/sources wyczyszczone, controls ponownie aktywne.
Podczas question disabled: text ASK/query, Voice Note start/stop, refresh i konfliktujące controls; STOP QUESTION aktywny wyłącznie podczas capture. Capture timer przestrzega istniejącego limitu 10 minut.
Całe recorder/STT/BGE/PostgreSQL/Qwen wykonują się na workerze; Qt UI thread nie wykonuje blocking model/database calls ani asyncio.run().
