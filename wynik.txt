3. Durable snapshot contract
Wspólny DatabaseSnapshot jest frozen dataclass ze slots:

4. TombstoneFingerprint contract
Frozen dataclass ze slots:
count: int
sha256: str
Fingerprint obejmuje dokładnie ingestion_id, memory_id, deleted_at.
Query: ORDER BY ingestion_id.
UUID serializowany kanonicznie jako string; deleted_at musi być timezone-aware,
jest konwertowany do UTC i zapisywany z dokładnością do mikrosekund.
Każdy rekord: JSON UTF-8, sort_keys=True, separators=(",", ":").
Hash: SHA-256 kolejnych rekordów poprzedzonych 8-byte big-endian length.
Publiczny wynik zawiera wyłącznie count i SHA-256.
Tombstone fingerprint nie zawiera contentu, metadata, session data ani vectora.
